# Frontend — Next.js

Giao diện web (từ vựng, kanji, ngữ pháp, hội thoại AI). Mọi request `/api/*` được Next.js chuyển tiếp sang backend (`BACKEND_URL`, mặc định `http://localhost:8080`).

```bash
npm install
npm run dev     # http://localhost:3100
```

Xem hướng dẫn chạy toàn bộ dự án ở [README gốc](../README.md).
